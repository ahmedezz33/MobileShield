# درع الجوال (MobileShield) 2.0 — Arabic / English

جدار حماية ومراقبة وإتلاف بيانات لأندرويد، **بدون روت**. كل الاتصالات تمر عبر VPN محلي داخل الجوال: لا يوجد خادم وسيط، وأنت المالك الوحيد. اللغة تُبدَّل بين العربية والإنجليزية من الزر أعلى الشاشة.

## التبويبات

| التبويب | ما فيه |
|---|---|
| **التطبيقات** | لكل تطبيق 4 أزرار: حظر على الواي فاي، حظر على بيانات الجوال، حظر عند قفل الشاشة، استثناء من حظر IP المباشر. يظهر حجم بيانات كل تطبيق، والحظر فوري |
| **السجل** | كل طلب DNS، وكل اسم موقع HTTPS، وكل اتصال TCP/UDP/ICMP: التطبيق والعنوان والنطاق والشبكة والنتيجة. الإعلانات المحظورة تُنسب للتطبيق الحقيقي الذي طلبها |
| **المراقبة** | سجل استخدام التطبيقات (متى فُتح كل تطبيق ومدته، وقفل الشاشة وفتحها)، وحجم بيانات وكاش كل تطبيق مع زر المسح، وآخر وصول لكل تطبيق إلى الكاميرا والمايكروفون والموقع وجهات الاتصال والرسائل وسجل المكالمات، وسجل الإشعارات، وسجل النظام (logcat)، و (أي تطبيق، أي كاميرا، مع تنبيه فوري)، والمكالمات العادية وVoLTE، واستهلاك البيانات من عدّاد النظام، وسجل المكالمات، والرسائل، والصلاحيات الحساسة، والشبكة الخلوية والأبراج |
| **التحكم** | قطع الإنترنت عن كل التطبيقات على الواي فاي أو بيانات الجوال، والسماح بالبيانات حسب الجيل (2G/3G/4G/5G)، وحالة الواي فاي والبلوتوث وNFC وQuick Share ووضع الطيران مع زر يفتح صفحة كل منها، والتطبيقات التي تملك الكاميرا أو المايكروفون، ومسار إيقاف التنزيل التلقائي في كل تطبيق مراسلة، وحظر خوادم وسائط واتساب |
| **الملفات** | **التنظيف العميق:** مسح الكاش لكل التطبيقات بأداة النظام، ثم فحص يعرض بقايا التطبيقات المحذوفة والملفات المؤقتة وملفات السجلات ومجلدات الكاش، وتُتلف بعد تأكيدك. يمسح أيضًا سجلات درع الجوال وتاريخه. **الإتلاف:** ملفات أو مجلدات، والمصغّرات، وسلة المحذوفات، والإشعارات، والحافظة، والكتابة فوق المساحة الفارغة. **الاسترجاع:** من سلة المحذوفات، ومن المصغّرات، ومن نسخ واتساب وتيليجرام |
| **الإعدادات** | الحماية من هجمات «بدون نقرة»، وإحكام الحماية، والاتصال المباشر بـ IP، وحجب الإعلانات، وخادم DNS، والنطاقات المخصّصة |

## التثبيت والصلاحيات

الطريقة الأسهل من الكمبيوتر: فعّل «تصحيح USB» في الجوال، ووصّله، ثم نفّذ:

```
powershell -ExecutionPolicy Bypass -File build-apk.ps1 -Install
```

هذا الأمر يبني التطبيق ويثبّته، ويمنحه الصلاحيات التي لا يستطيع طلبها بنفسه:

| الصلاحية | لماذا |
|---|---|
| `WRITE_SECURE_SETTINGS` | قفل «DNS الخاص» على الإيقاف |
| `GET_APP_OPS_STATS` | معرفة التطبيق الذي يستخدم المايكروفون أو الكاميرا |
| الوصول إلى الاستخدام | استهلاك كل تطبيق من عدّاد النظام |
| الوصول إلى كل الملفات | الإتلاف والاسترجاع |
| الوصول إلى الإشعارات | مسح الإشعارات |

بعد الانتهاء أطفئ «تصحيح USB»، فالصلاحيات تبقى ممنوحة.

**على الجوال بعد التثبيت:** فعّل «VPN دائم التشغيل» و«حظر الاتصالات بدون VPN» من الإعدادات، واجعل البطارية «غير مقيّد».

## ما لا يمكن فعله بدون روت (بصراحة)

- **إطفاء الواي فاي أو البلوتوث أو NFC أو 2G أو المايكروفون أو الكاميرا مباشرة من داخل التطبيق:** أندرويد يمنع ذلك على التطبيقات. التطبيق يقرأ الحالة ويفتح الصفحة المناسبة، والإطفاء بلمسة منك. أما قطع الإنترنت فينفّذه جدار الحماية فعليًا.
- **الكاميرا الأمامية والخلفية كلٌّ على حدة:** أندرويد يغلقهما معًا فقط.
- **تغيير «التنزيل التلقائي» داخل تطبيقات أخرى:** التطبيق يدلّك على المسار الدقيق في كل تطبيق مثبّت.
- **المكالمات العادية والرسائل SMS:** تُراقب ولا تُحظر.
- **حركة الأجهزة المتصلة بنقطة الاتصال:** تُكتشف وتُقاس فقط.
- **استرجاع ما حُذف نهائيًا:** الذاكرة مشفّرة وتُفرَّغ بعد الحذف. يُسترجع فقط ما زال موجودًا فعليًا.
- **هجمات «بدون نقرة»:** لا يمنعها أي تطبيق كليًا. الحماية الحقيقية هي التحديثات و«الحماية المتقدمة» أو «Auto Blocker».
- **الاتصال المباشر بـ IP:** ابدأ بوضع «تعلّم»، واستثنِ واتساب قبل الانتقال إلى «حظر»، لأن مكالماته تعتمد على هذا النوع من الاتصال.

## ما اكتُشف على هذا الجوال (S23 Ultra، One UI 9)

يفتح `com.samsung.android.ese` (SamsungSeAgent، تطبيق نظام من سامسونج) المايكروفون من 2 إلى 7 ثوانٍ كل بضع دقائق. يستخدم لذلك مصدر تسجيل خاصًا بسامسونج اسمه `SEC_BARGEIN_DRIVING`. التحقق تم بأمر `adb shell dumpsys audio`.

يفتح `com.samsung.android.smartface` الكاميرا الأمامية بكثرة (141 مرة)، والسبب ميزة «إبقاء الشاشة تعمل أثناء العرض» (`intelligent_sleep_mode`).

**ما عُطّل بطلبك (3 نوفمبر 2026)، وكيف تتراجع عنه:**

| الإجراء | أمر التراجع |
|---|---|
| تعطيل `com.samsung.android.ese` | `adb shell pm enable com.samsung.android.ese` |
| تعطيل `com.samsung.android.bixby.wakeup` (يعمل بهوية النظام، والتسجيلات انتقلت لاسم `com.samsung.oda.agent` بعد تعطيل ese) | `adb shell pm enable com.samsung.android.bixby.wakeup` |
| إطفاء «إبقاء الشاشة تعمل أثناء العرض» | `adb shell settings put system intelligent_sleep_mode 1`، أو من الإعدادات ← ميزات متقدمة ← الحركات والإيماءات |

## الرخصة

محرك الحزم في `app/src/main/cpp/netguard` مأخوذ من [NetGuard](https://github.com/M66B/NetGuard) ورخصته **GPLv3**. الاستخدام الشخصي حر. أما إذا نشرت التطبيق لغيرك، فيجب أن تنشر الكود كاملًا بنفس الرخصة.

## الكود

- اللغات والأدوات: Kotlin وJetpack Compose، والمحرك بلغة C عبر NDK 26.3.
- القيم المستخدمة: `minSdk 29`، و`targetSdk 34`.
- أدوات البناء (JDK وSDK وNDK وGradle) في `%LOCALAPPDATA%\MSTools`.

| الملف | الوظيفة |
|---|---|
| `ShieldVpnService.kt` | قرار السماح أو الحظر لكل اتصال |
| `Tracking.kt` | ذاكرة العناوين، والعناوين الوهمية، واستهلاك البيانات |
| `VoiceMonitor.kt` | المكالمات والمايكروفون والكاميرا |
| `Shredder.kt` / `Recovery.kt` | الإتلاف والاسترجاع |
| `Controls.kt` | حالة الاتصالات اللاسلكية والتنزيل التلقائي |
| `Guard.kt` | قفل «DNS الخاص» والتنبيهات |
| `Lang.kt` | اللغتان |
| `../i18n/` | أدوات استخراج النصوص وترجمتها |
| `../data/` | سجلات وصور الاختبار على الجوال |
