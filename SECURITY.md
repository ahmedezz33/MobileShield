# Security policy — سياسة الأمان

MobileShield is a security tool, so flaws in it matter. Please do **not** open a public issue for a vulnerability.

درع الجوال أداة حماية، والثغرات فيه مهمة. **لا تنشر** الثغرة في Issue عام.

## Reporting — الإبلاغ

Use GitHub's private reporting: **Security → Report a vulnerability**, or go directly to
<https://github.com/ahmedezz33/MobileShield/security/advisories/new>.

The report is visible only to the maintainer. Please include the app version, the Android version and steps to reproduce.

استخدم الإبلاغ الخاص في GitHub من الرابط أعلاه. يصل البلاغ إلى صاحب المشروع وحده. اذكر فيه إصدار التطبيق، وإصدار أندرويد، وخطوات تكرار المشكلة.

## Supported versions — الإصدارات المدعومة

Only the latest release receives fixes.

الإصلاحات تصدر لآخر إصدار فقط.
